# ⚡ Superhero AR Camera & VFX/SFX Studio

> Create Real-Time Superpower Videos: Hand-Tracking Live Fire AR, 8 Superpower VFX, Soundboard & Video Exporter.

## 🔥 Key Features
- **Live AR Hand-Tracking Fire Effect**: Rub your hands in front of the camera to ignite realistic flames on your palms! Move hands and fire follows with physics. Rub again to extinguish.
- **8 Superpower VFX Modes**: Lightning Arcs, Super Saiyan Aura, Blast Beam, Spark Portal, Ground Shockwave, Force Field Shield, Laser Eyes, Speed Teleport.
- **8 Pro Audio SFX (.WAV)**: High-impact sound effects tailored for video creators.
- **Direct Video Recording (.webm)**: Record live superhero action videos in browser and download immediately.
- **Video Editor Guide**: Instructions for CapCut, VN Video Editor, Premiere Pro, and After Effects using Screen Blending Mode.

## 🚀 How to Run
1. Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave).
2. Or run locally:
   ```bash
   node server.js
   ```
   Then open `http://localhost:3000`.
